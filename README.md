# О проекте

[![Logo Screen Shot][logo-screenshot]](https://github.com/Enot115/Conscience)

## Идея
Вы Подопытный № 52, чье тело стало объектом жестоких экспериментов в секретной лаборатории. Целью опытов было создание оружия, воздействующего на реальность через сознание, но в ходе финального эксперимента психика субъекта не выдержала и капсулировалась, защищаясь.


## Цель
Наша цель заключается в том, чтобы сделать атмосферную хоррор игру с элементами головоломки.
